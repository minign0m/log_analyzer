    Анализатор журналов ошибок
     Задача: открывать текстовые журналы (LOG/TXT), искать строки с ERROR и WARNING, фильтровать записи по уровню и тексту, сохранять отчёт.
     Выполнила: Маслухина Вероника
     Функции:
1. Открытие LOG/TXT-файла через диалог.
2. Поиск и подсветка/фильтрация строк с ERROR и WARNING.
3. Фильтрация по уровню (ALL, ERROR, WARNING, INFO) и по произвольному тексту.
4. Сброс фильтров и отображение всего файла.
5. Экспорт текущего отфильтрованного результата в отдельный файл.
6. Статистика: количество ERROR и WARNING в исходном файле.
Руководство пользователя:
* Открыть файл - выберите LOG/TXT. Содержимое отобразится, статистика обновится.
* Фильтр по уровню - выберите ERROR, WARNING, INFO или ALL.
* Фильтр по тексту - введите подстроку (регистр не важен) и нажмите «Применить фильтр».
* Сбросить - очищает фильтры и показывает весь файл.
* Экспорт - сохраняет текущее отфильтрованное содержимое в новый TXT-файл.
* Если файл не выбран или данных нет, программа показывает предупреждение.
     Как запустить
     1. Установите Python 3.8+.
     2. Сохраните код в файл log_analyzer.py.
     3. Запустите:
     python log_analyzer.py
     4. Откройте любой .log или .txt файл.
Пример тестового файла:
     2024-01-01 10:00:00 INFO Start
     2024-01-01 10:01:00 ERROR Database connection failed
     2024-01-01 10:02:00 WARNING Low memory
     2024-01-01 10:03:00 INFO Retry
     2024-01-01 10:04:00 ERROR Timeout
